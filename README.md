# Syx Sovereigns — Player Support

**English** | [Português (Brasil)](README.pt-BR.md)

Report bugs and share session logs for the Syx Sovereigns multiplayer mod for Songs of Syx.

This repository is a public support tracker. It contains reporting instructions and forms; the mod source code and game files are not hosted here.

## Report a problem

1. Sign in to GitHub and open the **Issues** tab above.
2. Search existing issues. If the same problem is already reported, add your experience and logs there, including your mod version.
3. Otherwise, select **New issue → Bug report (English)**, or choose **Relatar problema (Português)**.
4. Describe what you did, what you expected, and what happened. Attach the logs from the affected session.

English is the project's primary language. Full reporting instructions and a dedicated form are also available in Portuguese. Reports in either language are welcome. You do not need programming knowledge or Git installed. Please report one problem per issue.

**[How to find and attach your logs](LOGS.md)**

For multiplayer problems, logs from both the host and the affected guest are especially helpful. If you only have one side, submit it and explain which log is missing; the other player can add theirs in a comment later.

## Follow the investigation

Updates and requests for more information will appear in the issue comments. A report may need reproduction, more logs, a fix, or confirmation in a newer version. Please mention the exact version when retesting.

An open report does not by itself confirm the cause of a problem. A closed report does not necessarily mean a fix is already available in your installed version; read its resolution comment.

## Public attachments

Issues and uploaded files are public. Review logs and screenshots before sharing: they can include account identifiers, player names, local file paths, and session details. Remove personal information you do not want to disclose, and indicate that you redacted it. Do not upload passwords, access tokens, entire game folders, or saves unless specifically requested and you agree to share them publicly.

## Scope

Use this tracker for bug reports and diagnostic follow-up. General conversation can continue in the existing community chat. Code contributions are not being collected here at this stage.
